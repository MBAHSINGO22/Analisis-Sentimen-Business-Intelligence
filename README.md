<h2>📌 Tentang Project</h2>

<p>
Project ini merupakan implementasi analisis sentimen terhadap ulasan pelanggan e-commerce menggunakan Python dan teknik Natural Language Processing (NLP).
Analisis dilakukan untuk mengetahui sentimen pelanggan terhadap produk atau layanan berdasarkan data review yang diberikan.
</p>

<p>
Sistem akan mengolah data teks, melakukan preprocessing, kemudian mengklasifikasikan sentimen menjadi kategori seperti positif, negatif, atau netral.
</p>

<hr>

<h2>🎯 Tujuan Project</h2>

<ul>
  <li>Menganalisis opini pelanggan dari data ulasan e-commerce</li>
  <li>Melakukan preprocessing data teks</li>
  <li>Mengidentifikasi sentimen pelanggan</li>
  <li>Menyajikan hasil analisis dalam bentuk visualisasi</li>
  <li>Membantu evaluasi kualitas layanan atau produk</li>
</ul>
